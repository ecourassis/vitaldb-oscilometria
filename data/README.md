# Dados

Os dados integrais não são versionados neste repositório: a distribuição descompactada tem aproximadamente 95,4 GB. O notebook baixa somente metadados e os sinais necessários para uma amostra reprodutível.

Arquivos temporários são gravados em `data/cache/` e ignorados pelo Git. A redistribuição deve observar a licença e os termos da fonte escolhida (PhysioNet, CC BY 4.0). Não tente reidentificar participantes.
